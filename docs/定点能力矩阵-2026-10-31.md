# 定点能力矩阵（mcs2，2026-10-31）

> ✅ 现行。复现：`cd zig-0.17/tools/mcs2 && python feature_probe.py`

## 0. 一句话结论

**u8/u16/u32/i8/i16/i32 的基本计算已全通**：加减、乘、除、取余、移位（常量与运行期次数）、
比较（含跨 4 字节借位链）、按位与或异或取反、符号扩展、bool 返回 —— 一共是
**固定模板**（连续 vreg 槽 + 进位链 / MUL AB / 恢复法循环），不是类型系统；ABI 与 SDCC 对齐。
能力探针 **28 项支持 / 1 项拒绝**（只剩饱和算术 `+|`）；
**另外**：内部调用/间接调用（函数指针）、固定地址的多字节读写、**表下标（base + i*scale，scale=1/2/4）**、
**全局数组的符号基址**（`mov dptr,#_table`）、**函数指针表**（填表→查表→间接调用）、
**`const` 常量表**（初值发进代码段 `.db`，`movc` 读；CRC 表/字模/字符串都能用了）都已通；
仍缺：多字节全局变量（xdata 间接读写）、16×16→32 专用乘法、if 表达式（块返回值）；
`var` 的初值仍然不会被装载（RAM 掉电即失，`var` 当缓冲区用）。
所有拒绝都是**明确报错**，没有静默截断。

## 1. 多字节怎么做的（模板，不是类型系统）

一个 u16 值 = **两个连续 vreg 槽**（低字节在前），u32 = 四个。运算展开成固定指令序列：

| 运算 | 模板 |
|---|---|
| `u16 a + b` | `clr c; addc lo; addc hi` |
| `u16 a - b` | `clr c; subb lo; subb hi` |
| `u16 a << n`（n 常量） | 每步 `clr c; rlc lo; rlc hi`（低→高） |
| `u16 a >> n`（n 常量） | 每步 `clr c; rrc hi; rrc lo`（高→低） |
| `i16 a >> n`（算术） | 先 `sex` 取符号 → 逻辑右移 → 最高整字节覆盖 + 余位掩码 `orl` |
| `a << n` / `a >> n`（n 运行期） | 每轮 1 位循环：`rlc`/`rrc` 链 + `dec_br_nz`（次数 0 直接跳过） |
| `u16 a * b` | 3 次 `MUL AB`：`lo(a0b0)` + `hi(a0b0)+lo(a0b1)+lo(a1b0)` |
| `u32 a * b` | 32 轮移位加法（`br_c` 判位）；展开 10 次 MUL 省周期但费 ~200 B |
| `u16/u32 a / b`、`% b` | 恢复法循环：`(r:q)` 左移 → 试减 → 够减置商位、不够加回来 |
| `i*` 除/余 | `abs`（`sex`+二补码取负）→ 无符号模板 → 商按符号异或、余数随被除数 |
| 比较 `a < b` | 一条 `subb` 借位链 + `jc`；有符号版把最高字节两边 `xrl 0x80` |
| 比较 `a == b` | 逐字节 `xrl` + `orl` 累加 → `jz` |
| 比较当值用 | 物化 0/1：先置 0，取反条件跳过「写 1」 |
| 常量/加宽 | 逐字节 `mov`/`imm`；**有符号变宽补符号位**（`sex` → 0x00/0xFF） |
| 表下标 `p[i]`（运行期 i） | `dptr = base + i*scale`：先 `mov a,idx; add a,#lo; …; addc a,#hi`（第一遍带基址进位），
|  | 其余 `scale-1` 遍把「16 位加 idx」重复（`add a,dpl; …; addc a,#0`）；元素内第 k 字节用 `base+k`。
|  | scale 由元素类型宽度定（u8=1/u16=2/u32=4） |
| 表下标 `p[i]`（**符号基址**） | 基址是全局/静态变量 → `mov dptr,#_sym`（3 B）再叠 `off + i*scale`；
|  | 全局变量的汇编符号是 `_<未限定名>`（函数才是 `_<fqn>` + `_<导出名>` 别名） |
| 函数地址当值 `@intFromPtr(&f)` | `mov dptr,#_f` → 抄 DPL/DPH 成 2 字节；配合符号基址的表 + `@ptrFromInt` 就能做**函数指针表** |
| `const` 表 `tbl[i]` | 初值在**代码段**（`CSEG` 的 `.db`）：`mov dptr,#_tbl`（+off，+idx*scale）+ `clr a` + `movc a,@a+dptr`；
|  | 写 const 表直接报错。`const tbl = .{…}` 的运行期下标在 AIR 里是 `array_elem_val`（操作数是**聚合值**），
|  | 后端给它造一个函数内唯一的代码段符号再 movc |

**ABI**：u16 参数/返回值走 `DPL(低)/DPH(高)`；第 2 个及以后的 u16 参数按字节落在
`_名_PARM_3/_PARM_4`（`abi_byte` 游标）。参数在入口先搬进 vreg 槽，运算都基于槽。

## 3. 与定点格式的对应

| 目标 | 现状 |
|---|---|
| 8 位定点（UQ8 类） | ✓ 除饱和外可用 |
| Q15（i16） | ✓ 可用：i16 加减乘除余 + 算术右移 + 有符号比较；缺 16×16→32 专用乘法与饱和 |
| Q31（i32） | ✓ 可用：i32/u32 全基本计算；缺饱和（乘除走 u32 模板，i32 除法 305 B） |
| CORDIC | ✓ 依赖已齐（有符号加减 + 算术移位 + 有符号比较） |

## 4. 缺口按依赖排序（2026-10-31 晚更新：前三条已补齐）

1. ~~带符号类型（i8/i16/i32）~~ ✅ M2.21：`sex` 符号扩展 + 算术右移 + 翻符号位的有符号比较；
2. ~~多字节比较~~ ✅ M2.21：`cmp_wide_br` 一次发完整条借位链（gt/le 交换操作数）；
3. ~~多字节乘法~~ ✅ M2.22 / 除法 ✅ M2.23；
4. **多字节全局变量**（xdata 间接读写）：宽 `load`/`store` 目前只认连续 vreg 槽；
5. **饱和算术** `+|`：溢出检测 + 粘滞到边界（能力探针里唯一剩下的拒绝）；
6. **16×16→32 专用乘法**：4 次 MUL 展开（现在用 u32 模板可跑，但慢）；
7. **if 表达式**（块返回值）：需要 phi 语义，目前要求改写成 `var x` + if 语句。

## 5. 顺带修的 bug（本日）

1. **并行 codegen 数据竞争**：vreg/标签/临时标签是全局计数器，Zig 并行编译不同函数会撞车
   （`not8`/`xnor8` 同拿 base=0 → DSEG 槽重名）→ `generate()` 原子自旋锁串行化；
2. **ISR 尾声**：`Lower.is_isr` 漏赋值 → 只 push 不 pop、以 `ret` 结束；
3. **参数符号名泄漏**（SafeAllocator 报错）→ 逐个释放；
4. **测试驱动**：u16 返回要把 DPL/DPH 压栈保存后再建 DPTR（DPH 就是 DPTR 高位）。

## 7. 整型宽度支持（2026-10-31 晚实测）

| 类型 | 参数+返回 | 加减乘除 | 局部量 |
|---|---|---|---|
| **u8 / u16 / u32** | OK | OK | OK |
| **i8 / i16 / i32** | OK（含 bool 返回） | OK | OK |
| u1–u7 / u9–u15 / u5（u24 / usize / isize） | **Zig 前端口拒绝**（`parameter of type 'u1' not allowed in function`） | 算术闸门明确拒绝（不静默算错） | **可以当 1 字节容器存**（`storageBytes`），只是不能参与加减乘除 |
| i64 / u64 | 后端明确拒绝 | 拒绝 | 拒绝 |

> 关键区分：**存储宽度**（`storageBytes`：≤8 位 = 1 字节，16 = 2，32 = 4）与
> **算术宽度**（`requireIntWidth`：只认 8/16/32 且带符号位）是两套闸门。
> 前者让 `bool` 返回值、`u5` 移位次数这类值能落槽，后者保证不会把 u1 当 8 位算。

**两类拒绝要分清**：
- `parameter of type 'uN' not allowed in function` 是 **Zig 语言规则**（export fn 的参数必须是 C ABI 可表示的位宽），不是后端缺功能——即使后端实现了 u1 也过不了这一关；
- ~~有符号与 8/16 以外的返回宽度是后端限制~~ → 2026-10-31 晚已放开：±8/16/32 与 bool 都能当参数/返回值。

**修掉的一类静默错算**：以前 `wideBytes(ty) orelse 1` 把 u1/u64/i8 的局部量当 1 字节算——
实测 `var x: u1 = 1; x +%= 1` 得到 **2**（正确应为 0）。现在局部量/加减/移位/写回/读取
全部走 `requireIntWidth` 闸门，明确报「只支持 u8/u16/u32，当前位宽 N 位（有符号/无符号）」；
`int_cast` 保持透传（usize 下标要用），安全由算术闸门兜底。

## 8. 多字节 ABI（与 SDCC 对齐，2026-10-31 实测）

用 `sdcc -mmcs51 --model-small` 编 `unsigned long f(unsigned long a, unsigned long b)` 反汇编得到：

- **第 1 个参数**：低字节序进 **DPL, DPH, B, A**（最多 4 字节）；
- **第 2 个参数起**：进 `_名_PARM_2` 起的连续字节（u32 占 4 个）；
- **返回值**：同样 **DPL, DPH, B, A**（1/2/4 字节按需）。

mcs2 已按此实现（`spill_off` 游标从 2 起、`abi.arg_regs` 按序），所以 **u16/u32 的 C 互操作不需要 thunk**。

> 注：`MUL AB`/`DIV AB` 会破坏 B，而 B 是第 1 个参数的第 3 字节 —— 用到 B 作参数时，
> 乘法/除法前后会自动保存/恢复 B（`b_is_arg`）。
