# 定点能力矩阵（mcs2，2026-10-31）

> ✅ 现行。复现：`cd zig-0.17/tools/mcs2 && python feature_probe.py`

## 0. 一句话结论

**8 位无符号全齐**；**u16/u32 的加减与移位已通（固定模板 + 进位链）**；
仍缺：多字节乘法/比较、带符号类型（i8/i16/i32）、饱和算术、if 表达式。
所有拒绝都是**明确报错**，没有静默截断。

## 1. 多字节怎么做的（模板，不是类型系统）

一个 u16 值 = **两个连续 vreg 槽**（低字节在前），u32 = 四个。运算展开成固定指令序列：

| 运算 | 模板 |
|---|---|
| `u16 a + b` | `clr c; addc lo; addc hi` |
| `u16 a - b` | `clr c; subb lo; subb hi` |
| `u16 a << n` | 每步 `clr c; rlc lo; rlc hi`（低→高） |
| `u16 a >> n` | 每步 `clr c; rrc hi; rrc lo`（高→低） |
| 常量/加宽 | 逐字节 `mov`/`imm`（高位补零） |

**ABI**：u16 参数/返回值走 `DPL(低)/DPH(高)`；第 2 个及以后的 u16 参数按字节落在
`_名_PARM_3/_PARM_4`（`abi_byte` 游标）。参数在入口先搬进 vreg 槽，运算都基于槽。

## 2. 矩阵（19 项支持 / 8 项拒绝）

| 用例 | 结果 |
|---|---|
| add8/sub8/mul8(div8/rem8) | OK — `add`/`subb`/`MUL AB`/`DIV AB` |
| and8/or8/xor8/not8/xnor8 | OK |
| shl8/shr8/rot8 | OK（编译期次数） |
| bit_set（SFR 置位） | OK — `setb 0x99` |
| **u16_add / u16_args / u16_carry** | OK — 加减 + 进位链 |
| **u16_shl** | OK — 逐字节 rlc |
| **u32_add** | OK — 4 字节进位链 |
| bit_test / u16_cmp（`if (…) 1 else 0`） | 拒绝 — if 表达式（块返回值）未实现 |
| u16_mul | 拒绝 — 乘法只支持 u8 |
| i8/i16（参数、返回、算术右移、比较） | 拒绝 — 带符号类型未实现 |

## 3. 与定点格式的对应

| 目标 | 现状 |
|---|---|
| 8 位定点（UQ8 类） | ✓ 除饱和外可用 |
| Q15（i16） | **半通**：u16 加减/移位可用；缺 i16 符号、16×16→32 乘法、饱和 |
| Q31（i32） | u32 加法可用；缺乘法/比较/符号 |
| CORDIC | 依赖有符号 16/32 位加减+移位 → 只差符号与比较 |

## 4. 缺口按依赖排序

1. **带符号类型**（i8/i16/i32）：符号扩展、算术右移、有符号比较（`cmp` 的 `jc`/`jnc` 语义要换）；
2. **多字节比较**（`u16 a < b` 用 `subb` 链看 C）；
3. **16×16→32 乘法**：8051 只有 8×8→16 的 `MUL AB`，需要 4 次乘 + 累加模板；
4. **饱和算术** `+|`；
5. **if 表达式**（块返回值）：目前要求改写成 `var x` + if 语句。

## 5. 顺带修的 bug（本日）

1. **并行 codegen 数据竞争**：vreg/标签/临时标签是全局计数器，Zig 并行编译不同函数会撞车
   （`not8`/`xnor8` 同拿 base=0 → DSEG 槽重名）→ `generate()` 原子自旋锁串行化；
2. **ISR 尾声**：`Lower.is_isr` 漏赋值 → 只 push 不 pop、以 `ret` 结束；
3. **参数符号名泄漏**（SafeAllocator 报错）→ 逐个释放；
4. **测试驱动**：u16 返回要把 DPL/DPH 压栈保存后再建 DPTR（DPH 就是 DPTR 高位）。

## 6. 模板的尺寸（待优化）

| 用例 | 字节 | 说明 |
|---|---:|---|
| u16add / u16sub | 32 | 含加宽复制 |
| u16carry | 47 | 含常量物化 |
| u16shl / u16shr | 70 | 槽复制 + 逐字节 rlc |

目前每个操作都新开槽位，复制偏多；后续可做「宽值原地运算 + 复制消除」把 u16shl 从 70 B 压到 ~30 B。
