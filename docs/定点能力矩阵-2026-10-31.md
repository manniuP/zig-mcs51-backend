# 定点能力矩阵（mcs2，2026-10-31）

> ✅ 现行。复现：`cd zig-0.17/tools/mcs2 && python feature_probe.py`

## 0. 一句话结论

**8 位无符号**的加/减/乘/除/取余、与或非/异或、移位、位测试都能编；
**多字节（u16/u32）与带符号（i8/i16）全线未支持**——这是 Q15/Q31/CORDIC 的硬墙。
所有拒绝都是**明确报错**，没有静默截断。

## 1. 矩阵（24 项：支持 14 / 拒绝 10）

| 用例 | 结果 | 产物/原因 |
|---|---|---|
| add8 / sub8 | OK | `add a,dir` / `clr c; subb a,dir` |
| **mul8** | OK | `MUL AB`（低位在 A） |
| **div8** | OK | `DIV AB`（商在 A） |
| **rem8** | OK | `DIV AB`（余数在 B） |
| and8 / or8 / xor8 | OK | `anl/orl/xrl a,dir` |
| **not8** | OK | `CPL A` |
| xnor8 | OK | xor + cpl |
| shl8 / shr8 | OK | `clr c; rlc/rrc a` ×n（次数须编译期常量） |
| rot8 | OK | 左移 + 右移组合 |
| bit_set（SFR 置位） | OK | `setb 0x99` |
| bit_test（`if ((S&2)!=0) 1 else 0`） | 拒绝 | if 表达式/块返回值尚未实现 |
| sat_add8（`+|`） | 拒绝 | `add_sat` 未实现 |
| u16/u32 加减乘 | 拒绝 | 常量仅支持 u8（多字节未实现） |
| u16/i8 参数或返回 | 拒绝 | ABI 只有 u8（返回值 void/u8） |
| i8 移位/比较、i16 局部量 | 拒绝 | 带符号类型未实现 |

## 2. 与定点格式的对应

| 目标格式 | 需要的编译器能力 | 现状 |
|---|---|---|
| **Q7（i8）** | i8 参数/返回、算术右移、符号扩展、饱和 | ✗（i8 全线未支持） |
| **Q15（i16）** | 16 位加减（进位链）、16×16→32 乘法、算术右移、饱和 | ✗（被多字节卡住） |
| **Q31（i32）** | 同上 32 位 + 64 位中间结果 | ✗ |
| **CORDIC** | 有符号 16/32 位加减 + 移位 + 比较（不需要乘） | ✗（被宽类型卡住） |
| 8 位定点（如 UQ8/U8.8 变体） | 已有 8 位算术 | ✓ 除饱和外基本可用 |

结论：**Q15/Q31/CORDIC 不是缺算法，而是缺类型宽度**——一个都绕不过 u16/u32/i16/i32。

## 3. 缺口按依赖排序

1. **多字节类型**（u16/u32/i16/i32）：参数与返回 ABI（DPL/DPH/B/A 或 PARM 区）、
   `addc` 进位链、多字节比较、符号扩展；
2. **乘法**（`mul_wrap` 的 16/32 位形态）：8051 只有 8×8→16 的 `MUL AB`，
   16×16→32 要 4 次乘 + 累加，32 位更长；
3. **算术右移**（有符号 `>>`）与符号扩展（`int_cast` 有符号版）；
4. **饱和算术** `+|` `-|` `*|`（Q 格式常用，避免溢出回绕）；
5. **CORDIC** 本体是算法：只需 1–3 的产物，不需要新指令。

## 4. 本轮顺带修的两个 bug

1. **并行 codegen 数据竞争**：vreg 基址 / 标签域 / 临时标签都是全局计数器，
   而 Zig 会并行编译不同函数——两个函数拿到同一 base，DSEG 槽重名、
   汇编器报 `multiple definitions`（实测 `not8` 与 `xnor8` 都拿到 0）。
   修法：`generate()` 全程用原子自旋锁串行化。
2. **if 表达式**（块返回值）以前报「操作数 v1 尚无位置（内部错误）」，
   现在明确拒绝并给出改写建议。
