# mcs2 进展 · 2026-10-30 · M2 控制流第一刀

> ✅ **现行**（mcs2 M2 切片 1，M1/M1.5 之后）。
> 配套：`docs/迁移计划.md` §0、`docs/ADR-001-双ABI策略-2026-10-30.md`、`docs/研究-M2控制流与调用-参考实现-2026-10-30.md`

## 0. 结论

1. **AIR 控制流接通**：`br / cond_br / loop / block / repeat` 都能降级并发码，`while` 循环在 ucsim 跑通。
2. **比较融合**：`cond_br` 的条件若是 `cmp_lt/lte/gt/gte/eq/neq`，直接发 `cmp_br`（`subb+jcc` / `xrl+jz`），不物化布尔值。
3. **终止符追踪**：分支体已终止就不再补跳（省掉一条死 `sjmp`）。
4. **标签按函数分域**：跨函数不再重名（原先两个函数各自从 L0 开始 → 汇编器报 multiple definition）。
5. 全部既有验收（add / interrupt / selftest）保持全绿。

## 3. 生成代码（sum 的循环条件）

```asm
L12:                      ; loop 头
    mov _mcs_v3,_mcs_v2
    mov a,#0x00
    mov _mcs_v4,a
    mov a,_mcs_v3
    xrl a,_mcs_v4         ; i != 0 融合成 xrl + 分支
    jz L11
    ...
    sjmp L12              ; 回边
L11:
```

仍能看到每个值都过 DSEG 槽（`_mcs_vN`）——值驻留属于 P1，不在本刀范围。

## 4. 已知缺口（按优先级）

- [ ] **块布局**：当前按 AIR 顺序直发，未按 fallthrough 选边；
- [ ] **跳转松弛**：直接发 `sjmp`（±128），大函数会溢出；需统一发长跳再定点收缩（参考 AVR `-mrelax`）；
- [ ] **`djnz` 融合**：`dec_br_nz` 未建模；前置条件见研究文档 §1.3（计数器必须 R0–R7、单字节、无 FALSE 标签）；
- [ ] **`switch`**：`switch_br` 仍报“未实现”；
- [ ] **比较当值用**：`cmp_*` 只在 `cond_br` 里可用；被当布尔值消费会报“尚无位置”；
- [ ] **调用/内部 ABI**：`call` 未做（M2 后半段，按 Keil C251 的 R11,R7..R0 表）。

## 5. 下一步

1. 块布局 + 跳转松弛（先解决 `sjmp` 越界，再谈尺寸）；
2. `djnz` 融合；
3. 内部 ABI（ADR-001 的第二轨）；
4. `switch` 表。

## 6. M2 + 部分求值 工作清单（并行推进）

> 状态口径：[x] 已完成并验收；[ ] 未开始；[~] 进行中。按依赖排序，不按编号。

### 6.1 M2 主线

- [x] **M2.1 控制流降级**：br/cond_br/loop/block/repeat → MIR；比较融合；标签分域；终止符追踪
- [~] **M2.2 块布局**：已做“删跳到紧邻下一标签”（发射后压实）；按块选边（重排）未做
- [x] **M2.3 跳转松弛**：无条件跳转在 `ljmp`/`sjmp` 间定点收敛；条件跳转越界时展开成「反条件 + `ljmp`」。
      验收：`bigloop`（循环体 >128B）`big(3)=90` 通过，sdas 不再报 Branching Range Exceeded
- [~] **M2.4 djnz 融合**：MIR `dec_br_nz` + 发射 `djnz` + PE 解释已就绪；循环旋转 `rotateDjnz()` 也已写好，
      **但当前 lowering 把 `i -= 1` 物化成「load t,i; imm 1; sub u,t,1; store i,u」四段式，命中不了**——
      真正前置是 **P1 值驻留**（让变量留在槽里直接 `sub`）
- [ ] **M2.5 内部 ABI**：按 Keil C251 表（R11, R7..R0，最多 9 参；R12–R15 callee-saved）；call/ret 的 MIR 与发射
- [ ] **M2.6 边界 ABI thunk**：export/extern 处插入 SDCC ABI 转换（_名_PARM_n），thunk 只在边界
- [ ] **M2.7 switch**：≤7 项 4 字节 ejmp 表 + jmp @a+dptr；8–16 按速度/体积；>16 三张字节表重建 DPX
- [ ] **M2.8 复合指令进发射合同**：cjne/jb/jbc/setb 按操作数形态直出（不做事后窥孔）
- [ ] **M2.9 四基准验收**：add8/sumloop/memcpy4/bits 复现 + 与旧后端逐条归因

### 6.2 部分求值（PE）轨

- [x] **PE.1 切片 A**：无参 + 纯内部计算 + 有界步数 → 编译期解释执行 MIR，函数体换成常量写回 + ret
      （验收：sum_to()=44，反汇编无循环）
- [x] **PE.2 常量写回收紧**：`imm` 到直址直接发 `mov dir,#imm`；折叠体现为 `mov 0x82,#0x2C; ret`（4 B）
- [ ] **PE.3 带参数折叠**：实参 comptime 已知时先特化再折叠；否则保持运行期代码
- [ ] **PE.4 数组/全局缓冲**：常量下标的读写（load_xdata/store_xdata 已在，补 buf[j] 形态）
- [ ] **PE.5 屏障与阈值**：asm volatile / volatile 访问作为折叠边界；步数与代码膨胀上限
- [ ] **PE.6 内联 + 专门化**：库函数（如 uart_putc('A')）折叠成 mov SBUF,#0x41；依赖 M2.5
- [ ] **PE.7 fact 基准验收**：5!/15!/25! 折叠成 hex 常量（当前 SDCC/Keil/Zig 都不折，见 §7）

### 6.3 推荐执行顺序

1. **PE.2**（半小时级，先把已折叠的收益做实）
2. **M2.2 + M2.3**（布局 + 松弛：correctness 与尺寸的地基）
3. **M2.4**（djnz，循环尺寸第一枪）
4. **PE.3 + PE.4**（带参/数组折叠，接 fact 基准）
5. **M2.5 + M2.6**（内部 ABI 与边界 thunk）
6. **M2.7 + M2.8**（switch 与复合指令）
7. **M2.9 / PE.7**（双轨验收：四基准 + fact）

## 7. 附：三编译器“简化能力”静态对比（2026-10-30 实测）

同源 128 位阶乘（5/15/25，N 为字面量，不阻止优化）：

| 编译器 | 常量折叠 | 形态 | 代码量 |
|---|---|---|---|
| Keil C251 | 否 | 3 个独立函数，各 59 B | 177 B |
| SDCC | 否（会内联） | 三份循环内联进 main | 561 B |
| Zig（旧 mcs251 后端） | 否 | 共享 fact(n) | 646 B + 壳 |

结论：三家都不做编译期求值 → **PE 轨是 mcs2 的差异化能力**，PE.7 就是这条的验收。
