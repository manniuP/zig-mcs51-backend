## 怎么读

- **u16/u32 算术（u16mul 58 / u32mul 144 / u32div 188 / i32div 305）**：SDCC 与 Keil 都把
  乘除下沉到库（站点 3–15 B），mcs2 每处内联整段模板。公平比较要连库一起算 ——
  SDCC 的 `__divulong` 本身几百字节，**调用点多于两三个时库才划算**。
- **真程序形状（switch / ifexpr / consttab / indcall / cordic_sin）**：差距 1.3–2.0×，
  这是当前主战场。
- **table16 / table32**：mcs2 仍偏大（98 vs 28/43、393 vs 110/147），因为表下标还没在
  元素内复用 `dptr`。
- **sum_to_fold 4 B**：PE 折叠把整个循环吃掉，比两家都小 —— mcs2 的独有优势。
- **mcs2 DSEG 一列**：每函数一块静态槽；Keil/SDCC 是 0（参数在 R6/R7、返回在 R4..R7），
  这是结构性差距（见 `待推进` 的「寄存器 ABI」条）。
