## 2. 验收（全部实测）

- 单元测试：`peephole.zig` 3 条行为测试（穿线、死块删、直达性保留）+ mcs51/mir 全绿；
- 条目流对照：开启 `thread=1 dead_label=2 dead_jump=1`（`jnz L1`→`jnz L2` 穿线、
  L1 因前驱是条件跳被保守保留、L3+sjmp L4 死块删除）；关闭态保留全部原始条目；
- **ucsim 四点全 PASS**：`0x8000=07 / 0x8001=01 / 0x8002=00 / 0x8003=01`；
  关窥孔对照产物行为完全一致。

## 3. 0.17 的 API 坑（与 0.16 的差异，下次直接照做）

1. `std.mem.trimLeft` → **`std.mem.trimStart`**；
2. `std.posix.getenv` 在 Windows 无 libc 构建不可用；`std.process.Args.Iterator.initAllocator`
   需要 `Args` 实例（无全局获取）→ **开关用模块级 `pub var` + 多入口文件**最省事；
3. `std.debug.lockStderrWriter` 不存在 → 逐条 `std.debug.print`；
4. `std.ArrayList` 没有 `.writer(gpa)`（新 Io 体系）。
