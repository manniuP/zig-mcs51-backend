## 1 已完成：符号固定偏移折进重定位（原「交给 GLM」）

原来「符号基址 + 常量偏移」（`p.x`、`tbl[3]`、结构体字段）要发两条：

    mov dptr,#_sym
    mov a,dpl / add a,#lo / mov dpl,a / mov a,dph / addc a,#hi / mov dph,a   ; 12 B

现在一条（off 折进重定位加数）：

    mov dptr,#(_sym+0x0012)

- 先写探针汇编确认 **sdas8051 接受带加数的 16 位绝对重定位**（listing 里是 `90r00r12` 形式），
  sdld 链接后取值正确 —— 验收用例里 symtab 系列每个函数有 10 处走这条路径，ucsim 读回全对。
- 改动点：`mcs51.zig` 的 `emitDptrSym()` / `emitDptrSymIndex()` 改用新的 `emitSymReloc()`；
  顺手删掉失去调用者的 `emitDptrAdd()`。
- 一个带偏移的地址：**15 B → 3 B**。

## 2 已完成：表下标 scale 用一次 16 位乘（原「交给 DeepSeek」）

`scale = 2/4` 原来是把「16 位加 idx」**重复 scale 次**（scale=2 要 26 B，scale=4 要 38 B）。
现在：

    mov a,idx
    mov b,#scale
    mul ab                 ; 积在 B:A —— 是完整 16 位，不是丢高位的 8 位乘
    add a,#base_lo         ; 基址低字节直接折进这条加
    mov dpl,a
    mov a,b
    addc a,#base_hi        ; 进位照常往 dph 传
    mov dph,a

固定 **16 B**（符号基址那条先 `mov dptr,#(_sym+off)` 再 16 位加，共 19 B）。
idx 是 8 位、scale ≤ 4 → 积 ≤ 1020，16 位绝不溢出；**进位没有丢**。

- `MUL AB` 会踩 B(0xF0)，而 B 可能正载着本函数 arg0 的第 3 字节 ⇒ 新增
  `mir.Function.b_live`（= mcs2.zig 的 `b_is_arg`）：为真时用 `push 0xF0` / `pop 0xF0`
  包住那一段（+4 B，只出现在「arg0 ≥ 3 字节 且 用到带 scale 的表下标」的函数里）。
- 新增用例 `tests/btable.zig` 的 `bscale`：arg0 是 u32（第 3 字节进 B），先做一次
  scale=2 的写读（中间有 MUL），**之后**再取 `x >> 16` —— B 被踩坏就一定读错。
  现在 PASS，且 `bscale.asm` 里能看到 4 组 `push 0xF0` / `pop 0xF0`。

  清理缓存要清那里，不是源码树里的 `zig017/`。
