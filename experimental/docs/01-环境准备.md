# 01 环境准备

## 1. 目标

在 Windows 上准备出两套编译器，使同一个工程里的 C 与 Zig 都能编成
SDCC 的 ASxxxx 目标文件：

- C：**SDCC**（本机 4.5.20），提供 `sdcc.exe`、`sdas8051.exe`、`sdld.exe`；
- 251 目标用预编译的 **`tools/sdcc-mcs251-windows-x64/sdcc-mcs251/bin/`**（4.6.0，含
  `sdas251.exe`/`sdld.exe`）。
- Zig：预编译的 **`compiler/zig-out/bin/zig.exe`**（55 MB，自带 MCS 后端，
  含 `mcs51`/`mcs251` 目标定义）。这是目前**唯一可用**的编译器，见第 3 节。

## 2. SDCC（C 侧）

本机安装路径约定：

```
C:\Program Files (x86)\SDCC\bin\sdcc.exe
C:\Program Files (x86)\SDCC\bin\sdas8051.exe
C:\Program Files (x86)\SDCC\bin\sdld.exe
```

检查版本：

```powershell
& 'C:\Program Files (x86)\SDCC\bin\sdcc.exe' --version
```

本机 SDCC **只支持 `-mmcs51`**，不支持 `-mmcs251`。因此默认走 AI8051U 的
8051 兼容模式；要使用 251 核，需先自行编译 `sdcc-c251`（见 05 篇）。

## 3. 预编译 Zig 编译器（Zig 侧）

`zig/` 是基于上游 0.16.x 的源码树（含 `src/codegen/mcs/` 后端）。**当前不再走自举
重编编译器的路**：用 55 MB 版宿主构建出的 `zig.exe` 存在整数溢出/栈溢出（见
[07 调试笔记](07-调试笔记-ptr_rt自举崩溃定位.md)），无法验证后端源码改动。

因此本仓库固定使用一份**唯一可用**的预编译编译器：

```
mcs251\compiler\zig-out\bin\zig.exe     (55 MB, 构建于 2026-09-14 15:04)
mcs251\compiler（系统 zig 重建）\zig.pdb     (调试符号)
```

- 该目录已在 `.gitignore` 中忽略，二进制不入库。
- 使用前必须把 `ZIG_LIB_DIR` 指向本树的 `compiler/lib`（让它加载带 `mcs51`/`mcs251`
  目标定义的 `std`）：

  ```powershell
  $env:ZIG_LIB_DIR = "<workspace>\mcs251\compiler\lib"
  $zig = "<workspace>\mcs251\compiler\zig-out\bin\zig.exe"
  & $zig version   # 0.16.1
  ```

- `xmake.lua` 的 `--zig` 默认路径已指向该文件（旧 `driver/build.ps1` 已移除，改用 xmake）。

> 该 `zig.exe` 由 `compiler/` 源码用**系统 zig 0.16.0** 重建（含 `.ptr_rt` 修复、
> 运行期下标、COBS 所需能力等，见 [CodeGen.zig](../compiler/src/codegen/mcs/CodeGen.zig)）。
> 重建方法：`cd compiler; zig build -Doptimize=ReleaseFast -Dno-lib --zig-lib-dir <repo>\compiler\lib`。

## 4. 验证环境

### 4.1 Zig 后端能出汇编

```powershell
$env:ZIG_LIB_DIR = "<workspace>\mcs251\compiler\lib"
$zig = "<workspace>\mcs251\compiler\zig-out\bin\zig.exe"
Set-Content -Path empty.zig -Value 'export fn main() void {}' -Encoding ASCII
& $zig build-obj -target mcs51-freestanding "-femit-bin=empty.asm" empty.zig
```

成功会得到 `empty.asm`（ASxxxx 汇编文本）。

### 4.2 SDCC 能编 C

```powershell
$sdcc = 'C:\Program Files (x86)\SDCC\bin\sdcc.exe'
& $sdcc -mmcs51 --model-large -c t.c -o t.rel
```

成功会得到 `t.rel`。

### 4.3 头文件

工程用到的头文件位于：

- `include/`：`c51.h`（SDCC 语法宏）、`ai8051u_sfr.h`（AI8051U 寄存器）、`mcs_intrins.h`；
- `lib/stc-hal/`：STC 官方 AI8051U HAL 的 SDCC 化版本（GPIO、Delay、UART 等）。

编译 C 时用 `-I` 指到这两个目录：

```powershell
& $sdcc -mmcs51 --model-large -I <repo>\include -I <repo>\lib\stc-hal -c main.c -o main.rel
```

> 注意：SDCC 的 `-I` 要与路径**分开写**（`-I <dir>`）。写成 `-I<dir>`（紧贴）
> 在本机 SDCC 上找不到头文件。

## 5. 器件与主频

- 目标器件：STC **AI8051U**。
- 主频在 `lib/stc-hal/config.h` 的 `MAIN_Fosc` 中定义（示例工程为 40MHz）。
- 烧录时用 STC-ISP 把目标主频调成与 `MAIN_Fosc` 一致，否则 `delay_ms()` 不准。

详见 [05-移植到MCS-251](05-移植到MCS-251.md)。
