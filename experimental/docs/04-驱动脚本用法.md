# 04 驱动脚本用法

> **现状**：构建已统一到仓库根的 [`xmake.lua`](../xmake.lua)（`xmake f --mcs_arch=...` +
> `xmake build <目标>`）。旧的 `driver/build.ps1` **已删除**，本篇保留其命令行说明
> 作为「三段式管线」的参考；实际操作请用 xmake。各目标见
> [09-工程与示例总览](09-工程与示例总览.md)。

## 1. `driver/build.ps1`（单 Zig 源，已移除，仅作参考）

把 Zig 产物走完 SDCC 工具链并链接成 Intel HEX。

### 参数

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `-Source` | 必填，Zig 源文件 | — |
| `-Target` | `mcs51` 或 `mcs251` | `mcs251` |
| `-Out` | 输出基名 | 与源同名 |
| `-Zig` | `zig.exe` 路径 | `<repo>\compiler\zig-out\bin\zig.exe` |
| `-Sdas` | 汇编器 | mcs51：`sdas8051`；mcs251：占位 |
| `-Sdld` | 链接器 | 系统 `sdld` |
| `-LibDir` | SDCC 库目录（配 `-UseSdccLibs`） | mcs51：`…\SDCC\lib\large` |
| `-Crt0` | 启动汇编 | `driver\crt0-<Target>.asm` |
| `-UseSdccLibs` | 按 SDCC `.lk` 格式链接运行库 | 关 |
| `-NoCrt0` | 不链接自带 `crt0` | 关 |

### 示例

```powershell
# MCS-51：用系统 SDCC
.\driver\build.ps1 -Target mcs51 -Source .\examples\main.zig

# MCS-251：用自建 sdcc-c251 工具
.\driver\build.ps1 -Target mcs251 -Source .\examples\main.zig `
    -Sdas <sdcc-c251>\bin\sdas251.exe -Sdld <sdcc-c251>\bin\sdld.exe `
    -LibDir <sdcc-c251>\lib\large
```

产物：`<Out>.asm`、`<Out>.rel`、`<Out>.lk`、`<Out>.ihx`、`<Out>.map`。

> 该脚本一次只处理**一个 Zig 源**，不编译 C。C + Zig 混编见下一节。

## 2. `sdld` 命令文件（`.lk`）

`build.ps1` 生成的 `.lk` 与 SDCC 生成的结构一致：

```
-muwx
-i out.ihx
-M
-b HOME = 0x0000
-b XSEG = 0x0001
-b PSEG = 0x0001
-b ISEG = 0x0000
-b BSEG = 0x0000
-k <libdir>
-l mcs51
-l libsdcc
-l libint
-l liblong
-l libfloat
out.rel
-e
```

要点：

- `-b AREA = base` 设置**已存在**的存储区基址；无人定义该区会报
  `ASlink-Error-No definition of area ...`。SDCC 的目标模块会发出
  `HOME/GSINIT/...` 片段来定义这些区。
- 库只在有**未解析符号**时按需拉入。
- 符号带 `_` 前缀：C 的 `main` 就是 `_main`。

## 3. C + Zig 混编脚本（示例工程）

`examples/ai8051u_blink/build.ps1` 是一个可复用的混编脚本，流程：

```powershell
# 1) C -> .rel
& $Sdcc -mmcs51 --model-large @incArgs -c main.c      -o main.rel
& $Sdcc -mmcs51 --model-large @incArgs -c AI8051U_Delay.c -o delay.rel

# 2) Zig -> .asm -> .rel
$env:ZIG_LIB_DIR = Join-Path $root 'compiler\lib'
& $Zig build-obj -target mcs51-freestanding "-femit-bin=$ledAsm" $ledZig
& $sdas -plosgffw $ledRel $ledAsm

# 3) 链接（sdcc 自动补启动与运行库）
& $Sdcc -mmcs51 --model-large $mainRel $delayRel $ledRel -o $ihx
```

抄这个脚本改路径即可复用到自己的工程。要点：

- 头文件搜索路径分开写：`@('-I', $incDir, '-I', $halDir)`；
- `-femit-bin=` 用整体引号 `"-femit-bin=$ledAsm"`；
- 链接直接调用 `sdcc`（而不是 `sdld`），让它自动带上 SDCC 启动与库。

## 4. 脚本编码（重要）

含中文的 `.ps1` 必须是 **UTF-8 带 BOM**，否则 PowerShell 5.1 会用本地代码页
解析，导致中文乱码甚至语法错误（例如全角括号出现在字符串里）。

若用工具写成无 BOM，可补 BOM：

```powershell
$p = 'build.ps1'
$b = [System.IO.File]::ReadAllBytes($p)
$bom = [byte[]](0xEF,0xBB,0xBF)
[System.IO.File]::WriteAllBytes($p, $bom + $b)
```

> 注意别重复添加 BOM（文件开头出现两次 `EF BB BF` 会导致 `[CmdletBinding()]`
> 解析失败）。添加前可先检查开头字节。
