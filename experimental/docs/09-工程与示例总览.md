# 工程与示例总览

可上机的完整工程集合。每个工程都是「C（SDCC）+ Zig（MCS 后端）」混编，目录里有
自己的源码与 `build.ps1`；**工程说明文档已集中到本 `docs/` 目录**（见下表链接）。

| 工程 | 说明 | 文档 |
| --- | --- | --- |
| [`ai8051u_blink/`](../examples/ai8051u_blink/) | AI8051U 流水灯：STC HAL 驱动 P1，Zig 计算图案（8051 兼容模式） | [10-工程-ai8051u_blink](10-工程-ai8051u_blink.md) |
| [`ai8051u_ptrtest/`](../examples/ai8051u_ptrtest/) | C + Zig 3 字节指针互操作（M3） | [07-调试笔记](07-调试笔记-ptr_rt自举崩溃定位.md) |
| [`at89c52_sim/`](../examples/at89c52_sim/) | **软件仿真**自检测试：AT89C52 风格（标准 SFR），C 调 Zig 逻辑并校验，结果写 XRAM；可在 ucsim 里跑，无需开发板 | [07-调试笔记](07-调试笔记-ptr_rt自举崩溃定位.md) |

创建新工程的步骤与约定见 [01-环境准备](01-环境准备.md) 与
[03-C与Zig混编与ABI](03-C与Zig混编与ABI.md)。最小起手方式：复制
`ai8051u_blink/`，改 `main.c` / `led.zig` / `build.ps1` 中的文件与目标即可。
