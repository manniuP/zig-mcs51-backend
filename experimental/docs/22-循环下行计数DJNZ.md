# 22 - 循环下行计数 + DJNZ（构建层 `mcs_loop.py`）

> 把 MCS 后端生成的「计数 `while` 循环」改写为**下行计数 + `djnz`**，去掉每轮的
> 16 位比较、`i++` 帧搬运与回跳 `ejmp`。**构建层**完成，无需重编编译器。
> 配套：周期参考见 [21](21-指令周期参考与bench验证.md)、后处理链见 [15](15-汇编瘦身工具mcs_opt.md)/[17](17-后端IR提示与中间层优化.md)。

## 1. 动机

后端把循环归纳变量 `i` 放在帧槽，问题循环每轮形状固定（以 `data` 读循环为例）：

```
Lc:  mov a,@spx-<i0>        ; 16 位比较：
     mov @spx-<t0>,a        ;   拷 i 到 2 个临时槽            4
     mov a,@spx-<i1>
     mov @spx-<t1>,a
     clr cy
     mov a,@spx-<t0>
     subb a,#<lo>           ;   i - N
     mov a,@spx-<t1>
     subb a,#<hi>
     clr a
     addc a,#0x00
     jnz Lbody              ;   借位 = i<N                 3
     ejmp Lexit
Lbody:
     <真正的工作：读 1 + 加 2>
     <i++ 的 14 条帧搬运>                               14
     ejmp Lback                                         3
Lback: ejmp Lc                                         3
```

每轮 43 周期里，**约 34 是循环开销**（比较 14 + 自增 14 + 回跳 6）。

## 2. 变换

识别后改写为（`N = hi*256 + lo`，取 `rLo=lo`、`rHi=hi+(lo>0)`）：

```
     mov rHi,#hiAdj      ; djnz 先减后判，装载值 = 总次数
     mov rLo,#loN
Lc:                       ; 原条件块整块删除
     <body>               ; 原体，去掉 i++
     djnz rLo,Lc
     djnz rHi,Lc          ; 低字节减到 0 时减高字节；高字节到 0 退出
Lexit:
```

计数正确性：`djnz rLo` 从 `lo` 递减到 0（`lo>0` 时 `lo` 次），随后 `djnz rHi` 减高字节并回跳；
之后每轮 `lo=0→255` 记 256 次。合计：

- `lo>0`：`lo + hi*256 = N`；
- `lo=0`：`hi*256 = N`。

例：`N=500` → `rLo=0xF4`、`rHi=2`；`N=6000` → `rLo=0x70`、`rHi=0x18`。
`tools/mcs_loop.py --self-test` 对 1/2/100/255/256/257/500/511/512/1000/65535 做计数模拟（12/12）。

## 3. 安全约束（任一不满足则**跳过**该循环）

- 条件是**编译期常量**比较（`subb a,#lo`/`#hi`），`1 ≤ N ≤ 0xFFFF`；
- `body` 含调用时**不改写体**（仅换 DSEG 计数器，见 §4.1）；无调用时体折叠需匹配固定形状；
- 归纳变量槽 `i0/i1` 在 `body` 中**不被引用**（词边界匹配，避免 `@spx-0x1` 命中 `@spx-0x11`）；
- 循环后不再引用 `i0/i1`；
- `i` 在外层被 **0 初始化**（否则计数 ≠ N）；
- 寄存器计数器：所选寄存器在**整个文件**里未被使用（含 `@rN`）；
- 体折叠用到的临时寄存器（`edata`/`xdata`）同样取全文件空闲寄存器。

**默认关闭**：`MCS_LOOP=1` 才改写（与 `MCS_KEEP_BASE` 同一风格，工具内自判）。
`xmake/helpers.lua:postprocess_asm` 已无条件调用本工具，故只需设环境变量即可。

> **中断注意**：计数器是 `rLo/rHi` 两个字节寄存器。若某 ISR 会写这两个寄存器且不保存，
> 计数会被打断。**带中断的程序**要么让 ISR 避开这两个寄存器，要么关闭本优化
> （当前取「文件中未用」的寄存器，可降低但无法消除跨文件的中断风险）。
> 这也正是「寄存器提升」需要后端分配器的原因（见 [21](21-指令周期参考与bench验证.md) §5）。

## 4. 真机结果（AI8051U-34K64 @40MHz，`zigbench`）

`MCS_LOOP=1` 构建 `zigbench`；8 个循环被改写（`main` 6000 + 四个读 500 + `nop` 500 + 两个 `exec` 100）。
`exec` 的 body 含 `ecall`，改用 **DSEG 直接字节计数器**（`djnz dir8`，调用不影响）。
另外对四个读循环的**帧溢出体**做了折叠（见 §4.2）。串口抓帧（代表性一帧）：

| 项目 | 优化前 | 仅循环 DJNZ | +体折叠/+调用循环 |
| --- | --- | --- | --- |
| `nop` | 0x4305 (17157) | 0x0765 (1893) | 0x0865 (2149) |
| `rd d` | 0x5499 (21657) | 0x18f9 (6393) | **0x0e41 (3649)** |
| `rd i` | 0x5881 (22657) | 0x1de1 (7649) | **0x1229 (4649)** |
| `rd e` | 0x5a75 (23157) | 0x1fd5 (8149) | **0x1bed (7149)** |
| `rd x` | 0x5c69 (23657) | 0x21c9 (8649) | **0x1de1 (7649)** |
| `exe o0` | 0x47b5 (18357) | 0x47b5 | **0x3a8d (14989)** |
| `exe o5` | 0x48e1 (18657) | 0x48e1 | **0x3db9 (15801)** |

`data` 每轮 43 → 7 周期；相对原版总降幅：读循环 **−68%~−83%**，`exec` **−15%~−18%**
（`exec` 主要耗在被调函数体内，循环开销只占小头）。差分校验：
`d-nop = 3×500`、`i-nop = 5×500`、`e-nop = 10×500`、`x-nop = 11×500`——
与逐条周期表吻合，**迭代次数正确、访存不变**。数值含 `t0Now` 的 **±0x100 抖动**，百分比取近似。

### 4.1 两种计数器

- **无调用**：`rLo/rHi` 两个字节寄存器（快，不占 data），见 §2。
- **含调用**：body 里被调函数会踩寄存器，故用 **DSEG 直接字节** `_mcsloop_N`/`+1` 作计数器
  （`djnz dir8`，甚至比 `djnz Rn` 快 1 周期）；代价是每个循环多占 2 字节 data、且该循环不可重入。

### 4.2 体折叠（轻量寄存器/访存分配）

后端体是「溢出到帧槽再取回」的朴素形状，逐条周期高。对四种读体做**固定形状**改写：

| 读空间 | 原体（帧溢出） | 折叠后 | 体周期 |
| --- | --- | --- | --- |
| data | `mov a,S; mov T,a; mov a,D; mov U,a; mov a,T; mov r7,U; add a,r7; mov S,a` | `mov a,S; add a,D; mov S,a` | 9→3 |
| idata | 同上但读 `r0/@r0` | `mov a,S; mov r0,D; add a,@r0; mov S,a` | 11→5 |
| edata | 同上但 `dptr/movx` | `mov a,S; mov r3,a; mov dptr,D; movx a,@dptr; add a,r3; mov S,a` | 12→10 |
| xdata | 同上但 `dptr+dpxl/@dpx` | `mov a,S; mov r3,a; mov dptr,D; mov dpxl,H; mov a,@dpx; add a,r3; mov S,a` | 13→11 |

要点：`data`/`idata` 可用 `ADD A,dir8` / `ADD A,@Ri` 一带过；`movx`/`@dpx` 会占 A，
故用一个空闲寄存器（示例取 `r3`）暂存累加值。仅在**固定形状完全匹配**时改写，否则原样保留。

> 更通用的寄存器分配仍需后端分配器；本节是后端固定形状上的受限「寄存器/访存分配」。

## 5. 集成与回归

- `tools/mcs_loop.py`（`--self-test` 已并入 `tools/ci.ps1` 的回归段，始终运行）。
- **与差分回归的关系**：`mcs_regress.py` 断言「opt 只删 base 的行」；本工具会**改写**行，

- 复现：

```powershell
$env:MCS_LOOP="1"; xmake f --mcs_arch=mcs251; xmake build -r zigbench
python tools\bench_verify.py --port COM8 --baud 9600
```

## 6. 后续

- 已覆盖：无调用（寄存器计数）+ 含调用（DSEG 计数）的 16 位常量上界计数循环；四种读体的固定形状折叠。
- 体折叠目前只认四种「单次读-改-写」形状；更一般的表达式/多语句体未覆盖。
- 根治仍是后端**寄存器分配**：把归纳变量与常用量常驻寄存器（不经帧槽），可再降体开销
  （见 [21](21-指令周期参考与bench验证.md) §5）。
- 可扩展：8 位计数走单 `djnz`；小的 4/8/16 字节体做展开（同样用 `djnz` 计数）。
- 中断安全：后续可在启用循环改写时自动 `push/pop` 计数器寄存器，或直接支持寄存器分配。
