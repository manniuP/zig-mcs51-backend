## 1. 家族与外设互通（权威，来自用户口述）

| 家族 | 内核档 | 外设互通组 | 演进关系 | 备注 |
|---|---|---|---|---|
| STC89 / STC90 | `classic8051`（12T） | `classic` | 起点 | 最经典 51 |
| STC12 | `fast8051`（1T） | `stc12` | STC89 + 外设 | 双 DPTR / SFR 引脚映射 |
| STC15 / IAP15 | `fast8051` | `stc15` | STC12 + 外设 | 同一路线 |

> AI 家族：**AI8H 存在、AI8051U 存在**；AI32 的手册未在知识库（可能并入 STC32G/AI8051U 或需另行获取）。

说明：
- 片内 RAM「256 IRAM」= 低 128 `data` + 高 128 `idata`；1T 8051 的扩展 RAM 一律是 **xdata（MOVX）**，
  只有 **251 核**才有 `edata`（直接/间接、栈所在）。
- EEPROM 在 STC 上通常就是 Flash 同块（IAP），以 512B 为页擦除。
- XFR：STC8H 为 16 位 `MOVX @DPTR` 窗口并与片外 RAM `0FA00-FFFFH` 重叠；AI8051U/STC32 为独立
  24 位窗口 `7E:0000`。STC12/15 是否有 XFR 待核。

## 4. 生成器与回填流程

```
# 校验/摘要
python tools\mcs_device.py devices\stc\<part>.toml --emit summary
# 生成链接参数 / .lk / crt0
python tools\mcs_device.py devices\stc\<part>.toml --emit sdcc-args|lk|crt0
# 全部样例
python tools\mcs_device.py --self-test
```

回填顺序建议：先补 **存储布局**（`[code]`/`[[memory]]`/`[stack]`/`[interrupts]` 的确定值），
再接厂商头补 **SFR/XFR**（`[registers]` 与 `sfr_source`），最后加 `--emit sfr-header` 做交叉校验。
